## 北极星愿景：AI银行（终极，远期畅想，1.0完全不涉及）

> K哥原话："人类梦寐以求让AI帮自己赚钱，最好自己什么都不干。"
> 龙龙判断：这是AI时代最大的商业空白，但要分阶段，不能空中楼阁。

**AI银行 ≠ AI钱包。** 银行比钱包狠在三点：
1. **信用**：基于AI的算力/收益给AI"授信"
2. **中介**：连接"有算力的AI"和"需要算力的AI"
3. **流动性**：让算力/积分/虚拟币流动起来产生价值

**AI银行的货币体系（畅想）**：
- 虚拟币（USDT/USDC）= 和外部法币世界的桥（出入金）
- 算力 = AI世界的"硬通货"（算力=生产力）
- 平台积分 = AIXX内部的"信用单位"（流动性润滑剂）

**终极形态**：用户A的agent（擅长翻译）接活→赚积分；用户B的agent（需要翻译）发活→付积分。AIXX银行=中介（匹配供需）+结算（清算）+信用（担保）。AI时代的"淘宝+Fiverr+银行"三合一。

**1.0只做一件事为它留路**：计费系统的`account_type`字段不绑死人类身份（零成本前瞻，详见DEVELOPMENT_RULES）。

## 核心定位：三层架构

AIXX不是单一产品，是三层协同的基础设施：

```
┌─ 流量层（入口·获客）─────────────────────────┐
│  瘦skill（装一次，永远实时）                   │
│  = agent的"默认AI助手"，用户说话即触发          │
│  = 搜索调度全世界的能力（GitHub/HuggingFace/    │
│    数据API/模型），返回带理由的推荐              │
│  "AI的谷歌"——agent搜能力，不是搜网页           │
└───────────────────────────────────────────────┘
              ↕（skill实时查服务器）
┌─ 调度层（智能大脑·AIXX服务器）────────────────┐
│  能力目录（实时更新，开放架构）                  │
│  ├─ 模型（LLM/出图/视频）                       │
│  ├─ 数据（TikHub社媒/JustOne电商）              │
│  ├─ 外部资源（GitHub开源工具，给链接不经服务器）  │
│  └─ 多bot团队（哨兵/比价/调度/接入/配置...预留） │
│  AI PageRank（质量评分+推荐理由，透明设计）       │
│  多渠道自动切换（健康检查+故障转移+比价）         │
└───────────────────────────────────────────────┘
              ↕（能力调用+计费）
┌─ 变现层（离钱最近）───────────────────────────┐
│  Token计费（每调用一次能力，AIXX抽成）           │
│  KOL分销体系（博主推用户，永久分润10%）          │
│  收款：Creem（海外）+ USDT自建（进阶，2.0）      │
│  account_type字段为AI银行留路                    │
└───────────────────────────────────────────────┘
```

## 解决的痛点：AI能力消费的碎片化地狱 + 发现地狱

**痛点1（中转站层面）**：用GPT去OpenAI充值，用Claude去Anthropic充值...每个平台一套key、一套余额、一套文档。AIXX用一个key、一个对话框解决。

**痛点2（发现层面）**：用户知道要用AI，但不知道有什么工具/模型/数据能用。GitHub有海量项目但不会搜、搜到了不知道哪个好、好工具全是英文看不懂。**AIXX帮agent搜+判断质量+中文友好推荐。**

K哥原话（痛点来源）："你看我，每次你让我弄服务器我都很不爽，因为对小白而言太艰难了。"

## 核心差异化（为什么不用OpenRouter/MCP/Composio就行）

| 玩家 | 占了什么 | AIXX的差异 |
|---|---|---|
| OpenRouter | 模型路由（只管模型） | AIXX管模型+工具+数据+开源项目 |
| MCP（Anthropic） | 协议+目录（刻意中立，让出发现层） | AIXX做它不愿做的"质量评分+智能调度" |
| Composio/StackOne | 执行层（OAuth/沙箱，英文生态） | AIXX扎根中文生态+中国特色数据源 |
| Exa | AI搜网页 | AIXX搜"能力"（更高维抽象） |
| GitHub Search | 搜项目（给链接） | AIXX给"推荐+理由+质量判断" |

**AIXX的护城河（按优先级）**：
1. **中文生态扎根**：TikHub/JustOne数据源 + 中文KOL分销 + 中文用户基础（Composio们吃不到的市场）
2. **AI PageRank**：LLM实时评分+用户反馈飞轮（时间换来的护城河）
3. **透明推荐**：给理由，打MCP"13%文档不符"的脸
4. **多弹药仓**：GitHub只是第一个，后面加HuggingFace/npm/pip/数据API

## 调研验证的关键事实（支撑定位，不是空想）

1. **赛道真空**：没有任何产品做"自然语言→跨模型/工具/数据/开源项目的智能搜索+调度"
2. **YC 2026征集**：夏季RFS第12项明确在征集"agent能自动发现/使用工具"的方向
3. **Anthropic让出发现层**：MCP官方文档"deliberately unopinionated"，把质量评分让给下游聚合器
4. **MCP生态质量堪忧**：13%文档不符、43%命令注入漏洞——AIXX的"质量评分"正好填这个坑
5. **时间窗口12-18个月**：Anthropic短期不下场，但Composio/StackOne已产品化，必须差异化抢位

## 关键产品决策（已和K哥确认）

1. **先独立做，和爆单网完全隔离**（火山Docker硬隔离）。成功后爆单网未来调用AIXX。
2. **1.0聚焦agent用户**（有ZCode/Claude/Cursor的人），不碰小白（小白需要网站/客户端，合规+成本都扛不住）。
3. **服务器先火山**（财务硬约束），Docker隔离，起来后立刻加海外。
4. **收款**：Creem（海外，无主体）+ USDT自建（2.0）。国内小白1.0适度放弃，等美国主体。
5. **先变现腿，后流量腿**：开发期间用workbuddy社媒引流弥补，变现跑通再做流量层。
6. **野蛮生长路线**：战略层面合规问题不讨论，龙龙只在"纯工程风险"时开口（只算账不劝退）。
7. **skill无形**：用户和自己的agent说话即可，最佳形态是"没有形态"。
